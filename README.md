# Talabi — Order Management Dashboard

> Turn WhatsApp orders into organized, manageable orders. 📦

**Talabi** is an Arabic RTL order management dashboard designed to help small businesses and online stores organize orders, products, customers, and reports in one simple interface.

## ✨ Features

* 📦 Order management
* 🛍️ Product management
* 👥 Customer management
* 📊 Reports and statistics
* 📱 Responsive design
* 🌐 Arabic RTL interface
* 🔐 Authentication system
* 💾 Local data persistence using `localStorage`
* 🎨 Modern UI powered by Tailwind CSS
* 📋 Detailed order management
* 📱 Mobile-friendly navigation

## 🖥️ Main Screens

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### Open the project

```bash
cd talaby-app
```

Then open `index.html` in your browser.

For development, you can use **Live Server** with VS Code.

## 💾 Data Storage

The current version uses browser `localStorage` for authentication and application data.

No backend or database is required to run the current version.

## 🎯 Project Goal

Talaby aims to provide a simple way for businesses to manage their orders, customers, and products instead of relying entirely on WhatsApp conversations.
